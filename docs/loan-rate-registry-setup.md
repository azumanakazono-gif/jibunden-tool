# ローン金利マスタ（専用サービス導入手順）

## 構成方針
顧客データ管理とローン金利管理は、セキュリティと運用効率のため完全に分離する。
- 顧客データ：既存スプレッドシート／既存Apps Scriptを維持。既存の `API_TOKEN`、顧客保存・取得、使用者ログに変更を加えない。
- ローン金利：専用スプレッドシート＋専用Apps Script（本書の `gas/loan-rate/Code.gs`）で独立管理。
- フロントエンド：`loan-rate-registry.js` から金利専用GAS URLだけを呼び出す。顧客データ用GAS URLとは共有しない。

## 本番導入手順
1. 検証用で動作確認済みの専用GAS構成を確認する。テスト用GAS・DBは本番用に流用せず、本番専用のGoogleスプレッドシートとApps Scriptプロジェクトを新規作成する。
2. 本番専用スプレッドシートに紐づくApps Scriptへ `gas/loan-rate/Code.gs` を配置する。
3. 専用GASのスクリプトプロパティに `LOAN_RATE_ADMIN_KEY` を設定する。32文字以上のランダム値を使い、Bitwarden等で保管する。GitHub・HTML・ログ・シートにはキーを保存しない。
4. `appsscript.json` は `https://www.googleapis.com/auth/spreadsheets.currentonly` を指定する。専用スプレッドシートに紐づくスクリプトで使用し、顧客データ用スプレッドシートにはアクセスしない。
5. Webアプリを「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」でデプロイする。公開読込APIは金利マスタの内容のみ返し、書込APIは管理者キー必須。
6. PRプレビューは検証用GAS URLを使用し、本番DBへの書込みを禁止する。マージ後、main向け本番リリース設定で `window.JIBUNDEN_LOAN_RATE_GAS_URL` を本番専用GAS URLへ切り替える。プレビューと本番でURLを混在させない。
7. PRプレビューで読込・登録・誤キー拒否・再読込・履歴を確認し、問題なければPRをマージする。GitHubマージだけではApps Scriptは更新されない。

## API
- `GET ?action=loanRates`：共有金利を取得。
- `GET ?action=ping`：専用APIの疎通確認。
- `POST`（Content-Type: text/plain）：`action: saveLoanRate`、`product`、`month: YYYY-MM`、`rate`、`source`、`author`、`editorKey`。
- 書込は `LOAN_RATE_ADMIN_KEY` の一致が必須。未設定・誤入力は拒否。
- 登録者名は監査用の申告値であり、Googleアカウント本人確認ではない。

## 専用スプレッドシート
- `ローン金利マスタ`：商品ID × 適用年月で一意管理。
- `ローン金利変更履歴`：変更前後の金利、出典、登録者申告、更新日時を追記。
- 顧客情報・提案履歴・使用者ログは格納しない。

## 運用・セキュリティ
- 金利読込APIは公開情報として扱う。機密情報を金利マスタへ格納しない。
- 管理者キーは金利登録権限を持つ担当者だけに共有し、定期的にローテーションする。
- より強い本人確認が必要な場合はGoogle Workspace認証付きAPIへ拡張する。
- 金利の出典と適用年月を確認して登録する。前月金利を自動流用しない。
- 変動金利は将来一定を保証しない。

## オリコ 2026年11月（個別資料に基づく）
- `orico_fixed`: 固定 5.40%、10万～1,000万円、6～120回。太陽光・蓄電池／リフォーム、団信有無選択可（保険料はオリコ負担）。
- `orico_solar_variable`: 太陽光・蓄電池用変動 4.50%、10万～1,000万円、6～180回。
- `orico_general_variable`: 一般リフォーム用変動 4.80%、10万～1,000万円、6～180回。
- 取扱コードの照合注意: 個別チラシは太陽光用 `SB1`、一般リフォーム用 `SD1` と記載。一方、別紙「取扱条件表」の取扱番号は固定 `UA1`、太陽光用変動 `UK1`、一般用変動 `UM1`。コードを同一視せずオリコへ確認する。金利・上限回数は一致。
- 2026年11月の値は同月だけに適用。2026年12月へ自動繰越ししない。
- 本番GASは新しい商品IDに対応する版を個別に再デプロイする必要がある。GitHub PRのマージだけでは反映されない。
